# 手机远程访问

两条链路，别混：

| 你要在手机上用什么 | 靠什么 | 谁负责 |
|---|---|---|
| **DSH 本体**（对话、会话、批准、插件开关） | **DSH Go** App | App 连电脑上的 DSH（SSH 或 ds-harness-remote） |
| **H3 WebUI**（出片界面，8190） | **SSH 反向隧道 → 机主的服务器** | 对端机器起隧道，机主放行端口 |

> DSH Go 只管 DSH 自己，**不转发其它本地端口**；H3 WebUI 必须单独开隧道。

---

## 一、手机连 DSH：装 DSH Go + 引导连接

### 1. 下载与安装

- Android 8+：GitHub Releases 或官网 <https://go.dshtui.com/download>，常见手机选 **arm64** 包
- iOS：尚未公开发布，需在 Mac 上自行签名编译（`app/ios/`）
- 只连电脑上的 DSH **不需要**在手机装本机运行环境（省约 1 GB 空间）

### 2. 首次启动：三选一

| 选项 | 含义 | 什么时候选 |
|---|---|---|
| **本机** | 在手机上装 DSH 运行环境，全程在手机上跑 | 想脱离电脑用 |
| **远程主机** | 连电脑/服务器上已有的 DSH，不在手机装环境 | **推荐**（手机内存小、或想用电脑上的插件与工作区） |
| **和角色聊天** | 只用酒馆，什么都不装 | 只想聊天 |

### 3. 连"远程主机"（关键一步）

电脑上的 DSH 有两种被连方式：

| 方式 | 需要什么 | 特点 |
|---|---|---|
| **SSH** | 电脑开 SSH（Windows 自带 OpenSSH Server 即可），手机填地址+用户名+密钥/密码 | 简单直接；要求手机能访问到电脑（同局域网，或电脑有公网/内网穿透） |
| **ds-harness-remote** | 电脑装 `ds-harness-remote` 插件（v0.6.7，P2P + 端到端加密） | 不用开端口，跨网络更省事；但功能受限（插件只能开关、网页版不在主页带入对话） |

### 4. 装完怎么验证（引导清单）

按顺序做，每步都要有明确结果：

1. **切主机**：首页 → 切换主机 → 选刚加的远程主机，右侧应显示当前主机名
2. **发一句话**：在远程主机下发"你好"，能收到回复 = 通道通
3. **看工作区**：确认能看到电脑上的工作区/会话列表（说明权限与路径都对）
4. **看插件**：设置 → 插件，能列出电脑上已装的插件（远程模式只能开关）
5. **（可选）网页模式**：设置 → 界面 → 选「网页」；这是 **DSH 自己的网页版**，不是 H3 WebUI
6. **断线重连**：关掉 App 再打开，主机应仍然记住；对话列表不丢

### 5. 常见坑

| 现象 | 原因 |
|---|---|
| 连不上、一直转圈 | 手机到电脑没有可达路径（不同网段 / 电脑防火墙拦了 SSH / 隧道没开） |
| 能连但看不到工作区 | 远程主机的 DSH 工作目录配错，或 App 里选错了主机 |
| 网页模式打开是首页、不带对话 | DSH Remote 主机的网页版就是这个行为，官方文档明确写了 |
| 插件管理只有开关 | 远程模式的功能限制，不是 bug |

## 二、手机看 H3 WebUI：用自己的服务器转发

**端口由对端机器自己挑，机主只负责放行。** 流程固定为：

```
对端机器选一个端口  →  告诉机主  →  机主在云控制台放行  →  对端起隧道  →  手机浏览器打开
```

### 第 1 步：对端机器挑端口

在 **1024–65535** 里挑一个没被占用的，规则：

- 不要用 22 / 80 / 443（系统服务）
- 不要和机主已经用掉的撞车（本文示例：WebUI 用 **18490**，DSH 用 **3082**）
- 建议 5 位数随机段，例如 **18531**、**23477**

检查是否被占用（对端机器上）：

```powershell
Test-NetConnection -ComputerName 127.0.0.1 -Port 18531 -InformationLevel Quiet   # False = 可用
```

### 第 2 步：把端口告诉机主

一句话即可，例如：

> 我的 H3 WebUI 走 **18531**，请在服务器的防火墙放行 **TCP 18531**（入站，来源 0.0.0.0/0）。

**机主要做的**（云控制台 → 防火墙/安全组 → 加一条入站规则）：

```
协议 TCP ／ 端口 18531 ／ 来源 0.0.0.0/0（或只填对端出口 IP）
```

只加这一条，别动其它已有规则。

### 第 3 步：对端机器起隧道

服务器 sshd 需要 `GatewayPorts yes`（改法见 [`部署说明.md`](部署说明.md)，含备份与回滚）。

```powershell
# 把 -RemotePort 换成你报给机主的那个端口
powershell -ExecutionPolicy Bypass -File .\tunnel.ps1 `
  -RemoteHost 47.122.105.115 -User admin `
  -LocalPort 8190 -RemotePort 18531 `
  -KeyPath "$env:USERPROFILE\.ssh\id_ed25519"
```

`tunnel.ps1` 会断线自动重连；也可以由 `start-all.ps1` 带着起（把端口写进 `startup.json` 的 `tunnelRemotePort`）。

### 第 4 步：手机打开

```
http://<服务器IP>:<你选的端口>/?token=<WebUI 口令>
```

口令在 `webui/config.json` 的 `token` 字段——**必须设**，不然任何人拿到地址都能出片、翻你的作品库。

### 第 5 步：验证

在**任意能上网的设备**上：

```powershell
curl -s -o NUL -w "%{http_code}" "http://<服务器IP>:<端口>/api/health"                       # 期望 200
curl -s -o NUL -w "%{http_code}" "http://<服务器IP>:<端口>/"                                  # 期望 401（说明口令生效）
curl -s -o NUL -w "%{http_code}" "http://<服务器IP>:<端口>/?token=<口令>"                     # 期望 200
```

三条都对，手机就能用了。

## 三、安全红线

| 不要 | 原因 |
|---|---|
| 把 **3080 / 3081**（DSH 网页）直接映射到公网 | `dsh web` 没有登录口令，等于把任意命令执行权交给扫描器 |
| 把 **8190** 裸暴露、不设 token | 谁拿到地址谁能出片、能翻作品库 |
| 用 22/80/443 当转发端口 | 和系统服务抢端口，且更容易被扫 |
| 放行端口后不验证就关掉 | 端口开着、隧道没起，等于给扫描器留了个空门 |

## 四、端口对照（示例，端口以实际商量为准）

| 服务 | 对端本机 | 服务器 | 谁能访问 |
|---|---|---|---|
| H3 WebUI | 8190 | **由对端自选**（示例 18531） | 手机浏览器（带 `?token=`） |
| DSH 网页（如需） | 3081 | 不建议 | 只用 DSH Go App 连 |
| ComfyUI | 8188 | 不暴露 | 仅本机 WebUI 使用 |
