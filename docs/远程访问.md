# 手机远程访问（DSH 与 H3 WebUI 分开看）

> 这两件事经常被混在一起，其实是两条独立的链路：
>
> | 你要访问的东西 | 用什么 | 覆盖范围 |
> |---|---|---|
> | **DSH 本体**（对话、会话、批准） | `@xiazhi88/dshgo` 插件 + 手机 App | 局域网；出门要再加隧道 |
> | **H3 WebUI**（出片界面，端口 8190） | 本仓库的 `tunnel.ps1`（SSH 反向隧道） | 公网（走你自己的服务器） |
>
> dshgo 只暴露 DSH 自己，**不转发其它本地端口**；所以 H3 WebUI 必须单独开隧道。

---

## 一、DSH 手机联动：dshgo

### 它做了什么

`dsh web` 固定只监听 `127.0.0.1`（官方明确禁了 `--host 0.0.0.0`），并且 `/api` 有 Host/Origin 栅栏、会话 cookie 绑定 authority。手机就算连上 3080 也会被 401。

dshgo 把入站请求改写成 loopback，于是：

```
手机 App ──局域网/Tailscale──> dshgo :3081 ──改写为 loopback──> dsh web :3080
```

### 安装

```sh
dsh plugin --profile web add github:xiazhi88/dshgo -w
# 或走 npm（更快，免一次构建授权）
dsh plugin --profile web add @xiazhi88/dshgo -w
# 装完必须重启 dsh web
```

> **两个坑**（官方 README 明确写的）：
> 1. **装完必须重启 `dsh web`**，否则设置页签会出现但显示"服务端半没有运行"——不是装失败。
> 2. 从旧名 `dsh-lan` 升级要先 `dsh plugin --profile web remove dsh-lan`，否则设置里会出现两个同名"局域网访问"。

### 配置（可选）

profile 的 `cordis.patch.yml`：

```yaml
- id: dshgo
  config:
    port: 3081        # 对外端口，默认 3081
    bind: 0.0.0.0     # 对外绑定地址
```

端口被占用会自动往后试 10 个，启动日志会打印实际端口。

### 手机端

- 装好后 DSH 设置里多一个 **「局域网访问」** 页签：显示本机所有可用地址 + **二维码**
- Android App：<https://github.com/xiazhi88/dshgo/releases/latest/download/dshgo-app.apk>
- App 能力：会话跑完推送通知、**批准直接在通知栏点「允许」**、语音输入、主屏小组件

### 访问密码（强烈建议开）

转发端口默认对同网段所有设备开放。页签顶部可设密码：

| 客户端 | 看到的界面 |
|---|---|
| 浏览器 | 密码页，输一次记 30 天 |
| App | 原生解锁 → 指纹/面部/设备密码 |

实现细节（可信度较高）：密码用 **scrypt 加盐**存 `~/.dsh/dshgo-auth.json`（0600），改密码会**轮换签名密钥**让所有已解锁设备失效，且**改密码只接受本机请求**。

## 二、出门在外：给 dshgo 再开一条隧道

dshgo 只到局域网。出门要用，有两条路：

### 方案 A：SSH 反向隧道（和 H3 WebUI 同一套，服务器零安装）

```powershell
# 把本机 3081 映射到服务器的 3082
ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=20 `
    -i "$env:USERPROFILE\.ssh\id_ed25519" -p 22 `
    -R 0.0.0.0:3082:127.0.0.1:3081 admin@<你的服务器>
```

然后：
1. 服务器 sshd 需要 `GatewayPorts yes`（本仓库 `docs/部署说明.md` 有改法，含备份与回滚）
2. 云控制台防火墙放行 **3082/tcp**
3. 手机打开 `http://<服务器IP>:3082/`，仍然要过 dshgo 的访问密码

### 方案 B：Tailscale（dshgo 官方推荐）

设备级私有网络、点对点直连、不用开端口。dshgo 的页签会自动识别 Tailscale 是否就绪（认 `100.64.0.0/10` 的 CGNAT 地址）。

## 三、安全红线（别踩）

| 不要 | 原因 |
|---|---|
| 直接把 3080 / 3081 端口映射到公网 | `dsh web` **没有登录口令**，等于把任意命令执行权交给扫描器（dshgo README 原话） |
| 把 H3 WebUI 的 8190 直接暴露公网 | 同理；至少设 `config.json` 里的 `token` |
| 用弱口令或不设口令 | 公网隧道 + 无口令 = 任何人能出片、能翻你的作品库 |

## 四、端口对照表（本机 → 服务器）

| 服务 | 本机端口 | 服务器端口 | 谁来连 |
|---|---|---|---|
| H3 WebUI | 8190 | **18490** | 手机浏览器（带 `?token=`） |
| DSH（dshgo） | 3081 | **3082** | 手机 App 或浏览器（带 dshgo 密码） |
| ComfyUI | 8188 | 不暴露 | 只给本机 WebUI 用 |

两个隧道可以同时跑：`tunnel.ps1` 支持传不同 `-LocalPort/-RemotePort` 各起一个实例。
