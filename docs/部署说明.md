# 这个包里有什么

```
h3-studio-package/
├─ app.py                  WebUI 后端（aiohttp，单文件）
├─ static/index.html       WebUI 前端（单页）
├─ 启动.bat                 一键启动（自动找 ComfyUI 的 python）
├─ config.example.json     路径配置模板（可选）
├─ README.md               用法 + 实测数据
└─ workflows/              ★ 正在用的 3 套工作流模板（API 格式 + 变量声明 + 备注）
   ├─ minimax-h3-ref2v-community.json(.schema/.meta)        单图参考（最快，冷启约 5 分钟）
   ├─ minimax-h3-ref2v-community-multi.json(.schema/.meta)  7 图参考（保身份，约 8–10 分钟）
   └─ minimax-h3-ref2v-continue.json(.schema/.meta)         续接（末帧锚定在第 0 帧）
```

## 一、装工作流模板（给 DSH 用）

把 `workflows/` 里的 9 个文件**整个复制**到 DSH 插件的模板目录：

```
C:\Users\<用户名>\.dsh-comfyui-workbench\workflows\
```

复制完必须**让插件重载一次**，否则 `comfyui_run` 的预检会误报"缺节点"：

```
plugin_manager  action=set_bundle  target=dsh-comfyui-workbench  enabled=false
plugin_manager  action=set_bundle  target=dsh-comfyui-workbench  enabled=true
```

验证：`comfyui_workflow`（不带参数）应能看到 3 个模板；`comfyui_workflow {workflowId:"minimax-h3-ref2v-community-multi"}`
应返回 `missingNodes: []`，且 `models` 里是 `minimax_h3_ref2v_pruned_int8_convrot.safetensors`。

> ⚠️ 这套模板是**按我这台机器的工作流改的**，节点 id 是固定的：
> `12/40–45` 是 7 张参考图的 LoadImage、`16` 是 `MiniMaxH3ReferenceToVideo`、`47` 是续接的锚点图、
> `48` 是 `MiniMaxH3AddGuide`。如果你那台的基准工作流不同，**先打开 json 核对节点 id 再改**。

## 二、装 WebUI

1. 把整个 `h3-studio-package` 放到任意目录（比如 `D:\h3-studio`）
2. 想固定路径就 `config.example.json` → 改名 `config.json` 并填写：
   ```json
   {
     "comfyUrl": "http://127.0.0.1:8188",
     "port": 8190,
     "inputDir": "",      // 留空 = 自动从 ComfyUI /system_stats 的 argv 探测
     "outputDir": "",     // 留空 = 同上
     "workflowsDir": ""   // 留空 = %USERPROFILE%\.dsh-comfyui-workbench\workflows
   }
   ```
3. 双击 `启动.bat`

它按这个顺序找 Python：环境变量 `H3_PYTHON` → ComfyUI Desktop 自带 venv → PATH 里的 `python`。
**推荐用 ComfyUI 那个 venv**，因为它已经自带 `aiohttp` / `av` / `Pillow` / `imageio-ffmpeg`，不用再装。

启动后打开 <http://127.0.0.1:8190>。

## 三、验证清单

- [ ] 页面右上角显示 **ComfyUI 在线**
- [ ] "衔接源"下拉里能看到已有视频（说明输出目录探测对了）
- [ ] 拖 1 张参考图 + 3 秒 → 生成成功（这是最快的路径，约 3 分钟）
- [ ] 点"以此续接下一段"→ 生成 → 新片首帧应与上一段末帧几乎一致

## 四、这套模板和你文档里"自己建"的区别

文档里给的是**配方**（公开基准图 + 改动清单），这里是**成品**。差异：

| 项 | 文档配方 | 这个包 |
|---|---|---|
| 节点 id | 以 FlowForge 的 `H3_Balanced.api.json` 为准 | 同样源自它，已核对 |
| 参考图槽 | 需自己加 7 个 LoadImage | 已接好 `12/40–45` → `ref_images.ref_image_0..6` |
| 续接 | 需自己加 AddGuide 并改 BasicGuider | 已接好 `47/48`，`8.conditioning → ["48",0]` |
| VHS 参数 | 需自己补 crf/pix_fmt | 已写死 `crf 12 / yuv420p / save_metadata / trim_to_audio=false` |
| schema | 需自己写变量绑定 | 已声明 20+ 个变量（含 `last_frame` / `frame_idx`） |

## 五、注意

- 模板里的模型文件名必须和你那台的**完全一致**（`minimax_h3_ref2va_pruned_int8_convrot.safetensors` 等）。
  不一致就在 json 里改，或者把模型改成这些名字。
- `minimax-h3-ref2v-continue` 依赖 `MiniMaxH3AddGuide`（ComfyUI 内置，0.33+ 才有）。版本太老会 `missingNodes`。
- 输出节点用的是 `VHS_VideoCombine`（VideoHelperSuite），**不是**内置 `SaveVideo`。没装 VHS 会缺节点。
