# 项目结构总览（对照本机用）

> 目的：**每次拿到新版本，都能逐项对比"我这台机器缺什么"**。
> 仓库里只有 30 个受版本控制的文件；其余是运行期产物（已在 `.gitignore` 里，不该被同步）。

## 二、运行期文件（不进仓库，每台机器自己生成）

| 路径 | 谁生成 | 说明 |
|---|---|---|
| `startup.json` | `start-all.ps1 -Init` | ComfyUI 路径 + **隧道四件套**（`tunnelHost`/`tunnelUser`/`tunnelSshPort`/`tunnelRemotePort`/`tunnelKey`） |
| `webui/config.json` | 手写 | 访问口令 `{"token": "..."}`，**公网必须设** |
| `webui/jobs.json` | WebUI | 任务记录，重启后能恢复 |
| `webui/library.json` | WebUI | 作品库编号映射 |
| `webui/hidden.json` | WebUI | 隐藏的作品 |
| `webui/private.json` | WebUI | 私密库口令哈希 |
| `webui/joined.json` | WebUI | 拼接产物 → 来源映射 |
| `webui/calib.json` | WebUI | 耗时校准 |
| `webui/outputs/` `thumbs/` `uploads/` `asset_thumbs/` | WebUI | 产物、缩略图缓存 |
| `%USERPROFILE%\.dsh-comfyui-workbench\workflows\` | `sync.ps1` | **模板必须复制到这里才生效** |

## 三、逐项对比怎么做

### 方式 1：跑自查脚本（推荐，11 项一次看完）

```powershell
powershell -ExecutionPolicy Bypass -File .\verify.ps1
```

它会检查：版本是否落后、模板是否同步且一致、5 个必需模型、WebUI 源码、`startup.json` 隧道字段、口令、**桌面快捷方式是否指向 `start-all.ps1`**、ComfyUI/WebUI 是否在线、隧道进程是否存在。

任何 ✗ 都会在后面给出修复顺序。

### 方式 2：逐项手查

```powershell
# 1. 版本
git rev-parse --short HEAD ; Get-Content VERSION
git fetch origin ; git rev-list --count HEAD..origin/main     # >0 就是落后

# 2. 模板一致性（3 套 × 3 文件，逐个比哈希）
Get-ChildItem .\workflows\*.json | ForEach-Object {
  $d = Join-Path "$env:USERPROFILE\.dsh-comfyui-workbench\workflows" $_.Name
  "{0,-46} {1}" -f $_.Name, $(if (!(Test-Path $d)) { "缺失" } elseif ((Get-FileHash $_.FullName).Hash -eq (Get-FileHash $d).Hash) { "一致" } else { "不一致" })
}

# 3. 桌面快捷方式
$lnk = Join-Path ([Environment]::GetFolderPath('Desktop')) "H3 Studio.lnk"
if (Test-Path $lnk) { (New-Object -ComObject WScript.Shell).CreateShortcut($lnk).Arguments } else { "没有快捷方式 → 跑 make-shortcut.ps1" }
```

### 方式 3：文件级全量对比

```powershell
git ls-files | ForEach-Object { if (-not (Test-Path $_)) { "缺失: $_" } }
git status --porcelain        # 本地被改过但没提交的文件
```

## 四、桌面一键启动（必须自查）

**「H3 Studio」快捷方式不存在，或者不指向 `start-all.ps1`，等于没有一键启动，而且不会带隧道。**

```powershell
# 检查
$lnk = Join-Path ([Environment]::GetFolderPath('Desktop')) "H3 Studio.lnk"
$a = (New-Object -ComObject WScript.Shell).CreateShortcut($lnk).Arguments
$a -match "start-all\.ps1"     # True 才算对

# 没有或不对 → 重建
powershell -ExecutionPolicy Bypass -File .\make-shortcut.ps1
```

快捷方式带的参数决定了开机后会不会自动起隧道；隧道参数从 `startup.json` 的 `tunnel*` 字段读。

## 五、每次同步的标准动作

```
1. git pull / sync.ps1          → 拿新代码 + 同步模板
2. 重载 DSH 插件                → plugin_manager set_bundle 关→开
3. verify.ps1                   → 11 项自查，全 ✓ 才继续
4. 缺快捷方式 → make-shortcut.ps1
5. 缺 startup.json 隧道字段 → 补上
6. 缺口令 → 写 webui/config.json
```
